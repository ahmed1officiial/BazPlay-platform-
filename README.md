# BAZ PLAY — نموذج الواجهات الموسّع

## التشغيل
فك ضغط الملف، ثم افتح `index.html` في متصفح حديث.

## الصفحات الموجودة
- `index.html`: الصفحة الرئيسية للمشاهد، بتصميم سينمائي تقليدي.
- `catalog.html`: مكتبة الأفلام والمسلسلات مع البحث والتصفية.
- `details.html`: تفاصيل الفيلم أو المسلسل والمواسم والحلقات.
- `episode.html`: تظهر بعد اختيار الحلقة، وتعرض المترجمين المعتمدين المتاحين لهذه الحلقة.
- `translator.html`: الملف الشخصي العام للمترجم الذي يراه المشاهد.
- `watch.html`: صفحة المشاهدة مع اختيار الترجمة.
- `account.html`: نموذج واجهة تسجيل الدخول.

## التفاعل
- يمكن التنقل بين الصفحات واختيار مسلسل ثم حلقة ثم مترجم.
- زر الوضع الليلي/النهاري يحفظ الاختيار محليًا.
- الأسماء والأعمال والتقييمات وصور الخلفيات بيانات تجريبية.

## ملاحظة تقنية
هذا Front-end prototype فقط. لا يوجد خادم أو قاعدة بيانات أو بث فيديو فعلي أو تسجيل دخول حقيقي أو رفع ملفات SRT. يجب ربطه لاحقًا بخلفية آمنة ومحتوى مرخّص، وإضافة صلاحيات للمشاهد والمترجم والإدارة.
